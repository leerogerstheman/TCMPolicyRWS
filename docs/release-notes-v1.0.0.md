# TCMPolicyRWS v1.0.0 — 中医药政策与真实世界研究工具

面向**中医药政策文本挖掘**与**中医药真实世界研究（RWS）**的量化分析工具。
从中国政府网政策文件库采集中医药政策，建立可全文检索的语料库并分析政策变迁；
同时提供中药不良反应特征、用药依从性（PDC/MPR）、中成药联合用药模式、
DRG/医保付费下中医药成本结构等分析模块。

## 开发中修复的两个关键问题

### 1. 全部政策正文为空（严重）

首轮采集得到 168 条文档，标题、文号、机关、日期都正确，但 **`body_len` 全为 0 ——
正文一条都没抓到**。而本项目的核心价值就是政策全文检索与主题演变分析。

修复后：**183/188 成功抽取全文**。

剩余 5 份**并非解析缺陷**，而是数据源的客观限制：这些页面（主要为较早年份的
国务院文件）正文以**影印图片**（`<img>`）形式发布，页面中不存在可抽取的文本层，
另有 1 份为前端脚本注入的分页文档。工具会明确区分三类原因并记入
`body_status` / `body_error`：

| 状态 | 含义 |
| --- | --- |
| `image_only` | 正文容器内仅含图片（扫描件），**该文件本身没有可抽取文本** |
| `paginated` | 页面分页，正文由前端脚本注入，服务端 HTML 不含正文 |
| `node_missing` | 容器不存在，可能是页面结构变更 —— **这一类才提示解析器需修复** |

区分它们很重要：把前两类误记为"节点缺失"，会把数据源限制错误地报成代码缺陷。

### 2. 发文机关名称严重碎片化

原始数据中同一机构有多种写法（`中医药局` / `国家中医药局` / `国家中医药管理局` /
`中医药管理局办公室` / `国家中医药局综合司` …），且多部门联合发文被塞进一个字段，
空格与 `\u2002`（EN SPACE）混用。

不处理时按机关聚合会产生 **80+ 个"机关"**，其中多数实为同一机构，统计结果不可用。
归一化后收敛到 **22 个**，同时保留 `puborg_raw` 原始值保证可审计，并拆出
`puborg_all`（参与机关列表）与 `n_orgs`（联合发文机关数）。

## 数据边界（重要）

| 数据类型 | 来源 | 性质 |
| --- | --- | --- |
| 中医药政策文本 | 中国政府网政策文件库（`www.gov.cn`）公开检索接口 | **真实公开数据** |
| RWS 演示数据 | `examples/` 下 4 个 CSV | **人工构造的合成数据，非真实患者数据** |

- 本项目**不采集、不推断、不发布**任何真实患者数据，运行完整演示流程
  **无需任何真实患者数据**
- `examples/` 中所有文件头部均带显著的合成数据声明，其中任何"结果"
  **不具备临床、流行病学或实证含义**
- **不尝试绕过任何网站的反爬虫机制**。`nmpa.gov.cn`、`cde.org.cn`、`nhc.gov.cn`
  部署了 JavaScript 反爬保护，本项目不访问这些站点
- 不提供临床建议，不作为医保结算依据，不构成法律意见
- 不对政策条文作法律解释；政策原文以发布机关正式文本为准

## 模块

| 模块 | 内容 |
| --- | --- |
| **政策库** | gov.cn 采集、SQLite FTS5 trigram 全文检索（2 字词自动回退 LIKE）、机关归一化 |
| **政策变迁分析** | 年度/机关/主题分布、时间线、关键词演变、图表导出 |
| **中药 ADR 特征分析** | 性别/年龄/给药途径/品种/转归/关联性评价分布，含 χ² 检验 |
| **用药依从性** | PDC / MPR / 持续性计算，含 PDC≥80% 阈值 |
| **联合用药模式** | 中成药真实世界共处方模式分析 |
| **DRG 成本结构** | 中医药服务在 DRG 付费下的盈亏与保本费率 |

## 快速开始

```bash
git clone https://github.com/leerogerstheman/TCMPolicyRWS
cd TCMPolicyRWS

python tcm_rws.py crawl         # 采集真实政策数据（含正文抓取）
python tcm_rws.py info          # 查看采集结果与环境
python tcm_rws.py analyze       # 政策变迁分析（出图 + 导出 + 报告）
python tcm_rws.py search 中医药  # 全文检索
python tcm_rws.py rws           # RWS 分析（使用合成样例数据）
python tcm_rws.py demo          # 一键跑通全流程
```

依赖：pandas / numpy / matplotlib / openpyxl / XlsxWriter / beautifulsoup4。

```bash
python tests/test_core.py       # 42 通过，0 失败（无需 pytest）
```

## 工程细节

- **图表中文渲染**：不假定字体可用，而是实际绘制测试文本并捕获 matplotlib 的
  "missing from font" 警告来**验证** CJK 字体渲染成功（本机命中 Microsoft YaHei）；
  无可用字体时降级为**内置 SVG 生成**，因此不会出现豆腐块
- **无硬依赖降级**：matplotlib / openpyxl / bs4 缺失时分别降级到 SVG / CSV / 正则解析
- **统计严谨性**：χ² 检验以卡方分布 95% 分位点校验（χ²=3.841459, df=1 → p≈0.05）；
  期望频数 < 5 的格子占比 > 20% 时输出显式警告

## 局限

- **政策语料覆盖范围**：仅中国政府网政策文件库，主要收录国务院及部门层面文件；
  大量中医药技术标准、地方性政策不在此范围内
- **5 份影印件文件无正文**，已明确记录原因，未做 OCR（超出本项目范围）
- **RWS 全部使用合成数据**，仅验证代码逻辑正确性，不代表任何真实临床发现
- 政策主题分类基于关键词规则，用于辅助检索，不能替代对原文的阅读
- PDC≥80% 阈值源自心血管等慢性病领域研究惯例，用于中药场景需谨慎
